# 예약 업무 흐름과 카카오톡 안내 문구

## 업무 흐름

| 단계 | 할 일 | 도구 |
| --- | --- | --- |
| 1. 문의 | 달력에서 날짜 확인 후 카톡 상담. 날짜, 시간, 장소, 상품 확인 | 카카오톡 채널 |
| 2. 신청 | 신청서 링크 전달 → 고객 작성 → 메일 알림 도착 | 구글 폼, 시트 |
| 3. 예약금 | 계좌 안내 → 입금 확인 → 시트에 '예약금 입금일' 입력 | 시트 |
| 4. 확정 | 시트 '상태'를 **확정**으로 변경 → 달력에 '예약 마감' 자동 표시 → 확정 메시지 발송 | 시트, 캘린더(자동) |
| 5. 사전 상담 | 촬영 2주 전 행사 순서, 입장 시간, 돌잡이 시간 확인 | 카카오톡, 전화 |
| 6. 촬영·납품 | 상태를 촬영완료 → 납품완료로 변경 | 시트 |
| 7. 사후 | 후기 요청. 초상권 동의한 가족만 포트폴리오에 사용 | 시트 '추가 신청' 열 |

- 신청서와 예약금 입금이 모두 끝나야 확정한다. 입금 전에는 날짜를 잡아 두지 않는다.
- 같은 날 두 건이 들어오면 입금이 먼저 확인된 쪽을 확정한다.
- 취소되면 상태를 **취소**로 바꾼다. 같은 날 확정된 다른 예약이 없으면 달력의 마감 표시가 자동으로 지워진다.

## 카카오톡 안내 문구

### 1. 상담 후 신청서 안내

```
안녕하세요, 루시앤폴스냅입니다 :)
상담해 주셔서 감사합니다.

아래 신청서를 작성해 주세요.
https://docs.google.com/forms/d/e/1FAIpQLSdVMhrifVVVSYczf-3Rs4-lhAE--P_CJ6PWH1dbGJC6R_RlQQ/viewform

신청서 작성과 예약금 입금이 모두 완료되면 예약이 확정됩니다.
입금 전에는 날짜가 따로 잡히지 않는 점 참고 부탁드려요.
```

### 2. 예약금 안내 (신청서 접수 후)

```
신청서 잘 받았습니다!

예약금 10만 원을 아래 계좌로 입금해 주세요.
[은행] [계좌번호] [예금주]

입금자명은 '예약자_아기이름'으로 적어 주세요. (예: 김엄마_김하늘)
예약금은 상품 금액에서 차감됩니다.
변경·취소 규정: https://bongbongcola-bot.github.io/lucynpaul-snap/reservation.html
```

### 3. 예약 확정

```
입금 확인되었습니다. 예약이 확정되었어요!

▶ 촬영일: [날짜] [시간]
▶ 장소: [장소]
▶ 상품: [상품]

촬영 2주 전에 행사 순서와 입장 시간을 확인하는 사전 상담 연락을 드릴게요.
소중한 날을 함께하게 되어 감사합니다.
```

### 4. 촬영 2주 전 사전 상담

```
안녕하세요, 루시앤폴스냅입니다.
[날짜] 촬영 전에 몇 가지 확인 부탁드려요.

1. 행사 시작 시간과 장소 입장 가능 시간
2. 돌잡이 진행 시간 (사회자·업체 진행 여부)
3. 가족 원판 사진에 함께할 가족 구성
4. 꼭 담고 싶은 장면이나 소품

행사 시간이나 장소가 바뀌었다면 이번 주 안에 알려 주세요.
```
