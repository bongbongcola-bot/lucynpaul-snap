## 결정해 둔 것

- 순수 HTML/CSS/JS, 빌드 도구 없음. 파일을 기능별로 나눈다(친구들과 함께 보기 위함)
- 갤러리는 서명 있는 4:5 사진만. 리스트 밖 가족 사진이 섞인 현재 갤러리는 그대로 둔다
- 새로 쓰는 사진·영상은 초상권 활용 리스트에 있는 가족만
- 상품은 3개(앨범세트, 싱글앨범, 데이터)이고 가격은 사이트에 쓰지 않는다. 사진인화 타입은 추가 상품으로만 안내
- 데이터 상품의 스케치 영상은 초상권 활용 동의 시에만 포함
- 신청서가 들어오면 드라이브 '고객영수증안내' 폴더에 영수증 구글 문서가 생기고 알림 메일에 링크가 붙는다. 발송은 직접 복사해 문자·카톡으로. 계좌는 Apps Script 스크립트 속성 `DEPOSIT_ACCOUNT`에만 둔다 (2026-11-25)
- 하루 두 팀까지 촬영. 폼의 '촬영 시간대' 질문으로 오전·오후를 나누고 달력도 시간대별로 마감 표시 (2026-11-25)
- 예약은 '상담 → 신청서 → 예약금 입금'이 모두 끝나야 확정. 날짜를 미리 잡아 두는 홀드는 없음
- 예약금은 계좌이체 10만 원. 계좌번호는 사이트에 올리지 않고 카톡으로만 안내
- 공개 저장소라 커밋 메시지와 파일에 고객·아이 이름, 연락처, 계좌번호를 넣지 않는다
